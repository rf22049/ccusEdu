CCUS Edu — Illustration Asset Library

Cohesive 2D kawaii vector illustrations for the CCUS Edu website.
Palette: forest/teal green, mint, leaf green, cream, sky blue, warm soil brown,
with small yellow accents. Rounded shapes, friendly educational tone.

Each PNG is exported as an individual transparent crop. Some adjacent items
may remain grouped where they touched in the original illustration.

Folders:
- industrial_nature_education
- coco_game_education
- ccus_process_nature

Laravel:
Copy these folders into public/assets/ccus-edu_asset_library/.
Example:
<img src="{{ asset('assets/ccus-edu_asset_library/industrial_nature_education/industrial_nature_education_01.png') }}" alt="CCUS illustration">

Review and rename files to semantic names (factory.png, storage-cross-section.png,
leaves.png, etc.) before production use. See manifest.json for dimensions.
